# Pact

**A promise from you, to you.**

Pact lets your calm self set the rules that protect you on your worst day, and steps in before the damage is done.
Built at GreatUniHack 2026 for the NatWest challenge: *AI-Powered Financial Inclusion & Resilience*.

The full project plan (features, ethics, architecture, demo script) is in [PROJECT.md](PROJECT.md).

## Run the website

No install needed. Open `website/index.html` in a browser (double-click it in Finder). Everything is in that one file.

Current feature: **planned purchases**. Tell Pact about a big purchase in advance, wait out a cooling-off period
(24h under £100, 48h for £100–£499, 72h for £500+), then buy it without a hold. "Demo speed" makes 1 hour pass in 1 second.
